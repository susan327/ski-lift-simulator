# スキーリフト乗車体験シミュレーター

架空の「雪明かり高原」で、チェアリフトから雪山の景色や音を楽しむ一人称3Dシミュレーターの企画です。PCブラウザでの動作を想定しています。

画面左下の「リフト」で固定循環式ペアと自動循環式クワッドを切り替えられます。クワッドは駅構内で0.85m/s、本線で5.0m/sを目安に移動し、駅の前後で滑らかに加減速します。「ゲレンデ案内」では全体図と4コースを確認できます。クワッドでは山頂で降車後、目印に沿って約14mの緩斜面を自動で滑り出します。

## 起動方法

Node.js、npm、Python 3、WebGL 2対応のPCブラウザが必要です。フォルダ内で以下を実行して、ブラウザで http://127.0.0.1:8000/ を開いてください。

```powershell
npm ci
npm run dev
```

画面をドラッグすると一人称で見回せます。「三人称視点」でプレイヤーの背後から待機・乗車・滑走を見られます。「環境音を聴く」で駅の機械音と本線の風音を楽しめます。ペアの山頂では「こもれび林間を滑る」を押し、↑で加速、← →でターン、↓でブレーキ。麓に着いたら乗り場へ戻れます。時間倍率は1倍、2倍、4倍から選べます。降車後は「体験を終える」を押すと「もう一度乗る」が表示されます。
